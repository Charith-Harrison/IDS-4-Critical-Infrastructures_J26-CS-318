Severity concerns the effect on research conclusions, not a claim of malicious implementation. Historical source and artifacts remain in place for reproduction; the supported new path is separate.

The class-based fallback is a real code risk, but the saved manifest's counts do not show that it was needed for this particular run. Distinguish an exploitable implementation weakness from evidence that a specific saved result used it. Similarly, equal command signatures in train/test are expected for repetitive polling; without source/episode identity, that equality alone does not prove duplicate-instance leakage. The audit found no exact duplicate full raw CSV rows. The important demonstrated overlap is the shared dominant inferred replay segment.

The original split also has a generic fallback that drops the embargo when it would leave an empty side. Its returned descriptive strings assert independence without proving it. The saved 300-second gap reduces temporal adjacency but cannot establish recording/campaign independence. Related transactions and all source views must remain together; the new manifest additionally rejects known source filenames or identical observed events crossing partitions.

An explicit evidence column is an accountability check, not an automated proof that groups are independent. A student must verify it against run/capture logs. Group identity and missing annotations cannot be repaired by a library call, a random seed, a nicer folder structure or artificially partitioned gaps.
