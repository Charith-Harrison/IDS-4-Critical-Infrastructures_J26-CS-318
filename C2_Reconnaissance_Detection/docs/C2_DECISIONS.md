# C2 / RP2 — Methodological & Engineering Decision Log

Every major design choice in the `C2_Reconnaissance_Detection` component is recorded below with its empirical rationale and verification artifact.

---

| Decision ID | Decision Topic | Options Considered | Selected Option & Rationale | Verification Artifact |
| :--- | :--- | :--- | :--- | :--- |
| **`DEC-01`** | **Handling of `.csv.xlsx` Original Files** | (a) Rename/overwrite in place; (b) Read `.xlsx` on every run; (c) Stream once into `data/raw/*.csv` with SHA-256 checksum manifest. | **Option (c)**: Preserves original files in `Dataset/` completely untouched (`test_01`) while reducing I/O time from ~90s per `.xlsx` parse to ~1.2s per `.csv` load. | `data/raw/raw_manifest.json` |
| **`DEC-02`** | **Sequence Dataset Selection (As-Provided vs. Rebuilt)** | (a) Train only on as-provided `recon_sequences_ALL` (`175,800` windows); (b) Rebuild chronological windows within `(capture_group, session_id)` and evaluate both. | **Option (b)**: Audit proved that `99.38%` of as-provided sequences contain backward time jumps, `97.32%` cross `.pcap` files, and `67.70%` of `time_delta` values are `0.0`. Rebuilding within chronological streams (`119,237` windows) is essential to test `RQ1` and `RQ2` honestly, while keeping As-Provided in `ablations.py` for comparison. | `artifacts/sequence_audit.json`, `artifacts/rebuild_report.json` |
| **`DEC-03`** | **Simultaneous `2023-02-01` Multi-Interface Captures** | (a) Treat all 5 `2023-02-01` `.pcap` files as separate sessions/groups; (b) Deduplicate identical secondary interface captures (`282,076` rows) and merge into `G03_0201_veth`. | **Option (b)**: `veth665f3cf-0.pcap` (`65,610` rows, `50` positives) is a `100.0%` duplicate ($\le 1\text{ ms}$) of `veth4edc015-0.pcap` (`s0007`). Keeping both across train/test would leak all `10` positive windows in `G03`. | `artifacts/rebuild_report.json`, `artifacts/leakage_audit.json` |
| **`DEC-04`** | **Exclusion of `attached_recon_flows.csv` (`14` rows)** | (a) Pad 2–4 packet flows to length 20; (b) Exclude from 20-packet windowing and log in `packet_exclusions.csv`. | **Option (b)**: Those 14 rows belong to 4 sessions (`s0014..s0017`) with only 2–4 packets each (already excluded from the as-provided `recon_sequences_ALL`), lack calendar dates in `timestamp`, and use multicast/broadcast IPs. | `data/rebuilt_sequences/packet_exclusions.csv` |
| **`DEC-05`** | **Primary Independence Grouping (`capture_group` vs. `session_id`)** | (a) Group by `session_id` alone; (b) Group by `capture_group` (`LOCGO-10` primary + `SGKF-5` secondary) and report `session_id` grouping as a diagnostic. | **Option (b)**: In this dataset, `session_id` is a directional host pair (`src_ip->dst_ip`) spanning up to 9 `.pcap` files, and `94.20%` (`1,769 / 1,878`) of all positive windows occur in `s0004` (`185.175.0.5 -> 185.175.0.3`). Grouping by `capture_group` holds out complete independent capture episodes while preserving all directional flows per capture; we also report `loso_session_5fold` in `ablations.py`. | `artifacts/folds.json`, `artifacts/ablation_results.json` |
| **`DEC-06`** | **Window Boundary Self-Containment at $t=0$** | (a) Use packet $i_0 - 1$ outside the window for $t=0$ deltas; (b) Zero/NaN transition deltas at $t=0$ of each 20-packet window. | **Option (b)**: Ensures every 20-packet window is 100% self-contained with zero leakage from packet $i_0 - 1$ and guarantees exact mathematical parity between batch training tensors and standalone 20-packet runtime inference (`POST /predict`, verified by `test_10`). | `src/features.py`, `tests/test_c2_pipeline.py` |
| **`DEC-07`** | **Addressing the `modbus_len == 3` (`packet_size == 75`) Shortcut** | (a) Ignore that `modbus_len == 3` has `100%` precision on `94.99%` of positive windows; (b) Run primary comparison with all verified protocol features AND run a dedicated Shortcut-Removed Ablation removing `modbus_len` and `packet_size`. | **Option (b)**: Preserves fidelity to the approved 7-feature proposal schema in the primary comparison while isolating genuine sequence/timing detection power when the trivial frame-length shortcut is removed. | `src/ablations.py`, `artifacts/ablation_results.json` |
| **`DEC-08`** | **Deep Learning Framework Selection** | (a) TensorFlow/Keras; (b) PyTorch (`torch 2.14.1+cpu`). | **Option (b)**: Python 3.14 environment supports PyTorch natively with deterministic CPU execution, exact input-gradient attribution, and `<2 ms` single-window inference latency while implementing the exact approved architecture (`LSTM(64) -> Dropout(0.3) -> LSTM(32) -> Dropout(0.3) -> Dense(16, ReLU) -> Dense(1, Sigmoid)`). | `src/train_lstm.py`, `artifacts/latency.json` |
