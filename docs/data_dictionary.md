# Data and feature contract

The machine-readable source audit is `results/metrics/dataset_audit.json`.
The complete active whitelist is generated by `src.feature_engineering.feature_groups`
and recorded in each model's metadata and feature_names.json.

| Processing field | Purpose | Model input? |
| --- | --- | --- |
| attack_category | Authoritative configured target | No |
| attack_sub_type, is_attack | Label audit only | No |
| source_file, source_row, event_id | Trace back to original CSV row | No |
| file_source / capture_id / scenario_id | Group boundaries | No |
| timestamp, frame_number | Order and reset inference | No |
| src/dst IP and port | Bidirectional session reconstruction | No |
| mbtcp_trans_id | Request/response lookup | No |
| group_id, context_id, partition | Isolation boundaries | No |
| function_code, is_read, is_write | Current protocol operation | Yes |
| address, value, word/bit/byte count | Exported current-event fields | Yes |
| unit_id, is_request, is_exception | Current protocol semantics | Yes |
| lag/window/transition fields | Past-only contextual evidence | Contextual RF only |
| partial match/delay/mismatch fields | Earlier request evidence on a response | Contextual RF only |
| *_missing | Absent or inapplicable feature indicator | Yes |

Missing optional numeric fields remain NaN until the training-fitted median
imputer. All-missing training features use zero with a missingness indicator.
Malformed supplied numerics, range errors and missing function codes are
quarantined. Unknown labels or conflicting auxiliary attack flags stop training
rather than being guessed. Inference ignores labels and never assigns a class
to malformed rows. Quarantines preserve original IDs and exclusion reasons.

Input column names normalize to lowercase snake_case; configure raw-to-canonical
aliases in dataset.column_map. Configure label_column using its normalized name.
Timestamps support seconds, milliseconds, microseconds, nanoseconds or ISO strings.
Rows without time cannot support timing/pair features. Reliable groups or full
timestamps are required for train/validation/test splitting.
