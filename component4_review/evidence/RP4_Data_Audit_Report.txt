6. Audit Findings & Protocol Pipeline Recommendations
1. Strict Row-Level Labeling: The replay file contains both benign and attack packets. Labels are strictly audited at
row level and never inferred from filenames.
2. Transaction-Level Context Scoping: Transactions are paired using 8-tuple (capture_id, client_ip, server_ip,
client_port, server_port, TID, Unit ID, Function Code) rather than TID alone, preventing identifier collision.
3. Temporal Leakage Elimination: Data splitting employs independent capture files and chronological blocking with a
300-second separation gap to guarantee test isolation.
4. Verification Status: Data audit verified 100% integrity across all required protocol fields. The datasets are certified
ready for feature extraction and model training.
