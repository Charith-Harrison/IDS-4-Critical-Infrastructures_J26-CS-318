# Unresolved assumptions and limits

No item below is silently resolved by increasing the positive class count or citing an old audit.

| Issue | What is established | What remains unproven / evidence needed |
| --- | --- | --- |
| Original workbook extraction and labels | Positive CIC rows can largely be mapped to raw bytes; strong semantic label contamination is demonstrated | Original PCAP-to-workbook extraction, sampling, label generation and event-map programs are absent. Reconstructing an empirical rule does not prove the creator's historical algorithm. |
| Missing historical rebuilt files | New independent reproduction matches population/window summary counts | Original historical CSV/NPY bytes, IDs and exact contents cannot be validated without those files. |
| External attached-flow snippet | 14 time-only rows, 12 positives, different subnet and very short groups | Original source PCAP/experiment ledger/date/labels are unknown. No current date is inferred. |
| Independent acquisition campaigns | Substation1–17 are a continuous rotation chain; mirrored interfaces are dependent | No source-backed reset/acquisition ledger establishes finer independent experiments. Campaign count stays null/unknown. Dates, TCP connections and tool starts are not substitutes. |
| Original log clock | Many target/range probes occur close to original starts; every candidate reference was checked | Global logger clock synchronization and causal exact event attribution are not established. Matching uses an explicit 25ms contextual bound. |
| Multiple eligible start rows | 320 candidates have several eligible original starts | These remain ambiguous. Their recon-probe context does not make a particular event reference unique. |
| Completion rows / transaction IDs | Some completion TIDs exceed the uint16 wire range; external CSVs omit target/TID columns | Completion sentinels and repeated TID0 must not be coerced into unique transactions. Generator semantics are not available. |
| Incomplete raw ADUs | Complete request/response ADUs and their exact bytes were recovered and independently verified | The bounded extractor does not reassemble arbitrary TCP segmentation. Missing/unframed ADUs are counted, not reconstructed by guessing. More recovery remains possible. |
| Packet versus message identity | Two inherited packet rows contain 23 coalesced ADUs each | A packet row cannot automatically represent one unique message. Exact ADU offset is required. |
| Response pairing | 269 saved response byte strings were checked in original frames | Reverse endpoints/TID/unit/function and timing support candidate associations; full connection-generation and unique transaction proof is not universal. No response is invented for unmatched requests. |
| FC5 positive cohort | All 8,400 are 0x85/code3 replies to invalid coil-value writes; nearby logs are brute/specific-coil | This does not make every nearest log a uniquely proven exact event. It strongly contradicts the claimed initiating reconnaissance label. |
| Other inherited positives | Wrong-target mappings, query-flood context and unsupported quantity heuristics are documented | Final relabeling requires an explicit frozen target/evidence policy; labels were not automatically overwritten here. |
| Negative rows in attack captures | Inherited label0 is a property of the processed file | It is not verified benign truth. In particular, requests causing old positive responses may themselves be malicious. Absence of a nearby recon log is not a normal label. |
| Normal lookalikes | All 2,042,925 read requests in the canonical benign HMI view use quantity1; no exact current-message match for 148 contextual candidates | Other legitimate maintenance/multi-register behavior is not supplied in that census. No claim is made about all possible normal deployments. Other NIC views are not presumed independent experiments. |
| Temporal histories | Per-target/unit causal histories and exact request gaps are available; observed marginal differences are shown | No matched-shape, independent evaluation establishes incremental temporal value. Cross-target enumeration is not measured by per-target histories. |
| Idle threshold and sequence length | Diagnostic histories reset after 60s; reconstructed old windows use20/stride5 | These are diagnostic choices, not validated universal deployment settings. Sensitivity and latency including acquisition must be prespecified in a valid later experiment. |
| Unit/device and sequential scanning | Recovered probes use unit1 and mainly fixed start address1 with range/function variation | Sustained sequential starting-address scans and unit-ID enumeration are not established by this recovery. |
| Baseline interpretation | Fixed current-message rules explain inherited labels; conservative source-family learned diagnostics transfer poorly | Neither result validates the inherited target or proves an LSTM necessary. Final models are deferred. |
| Primary collection claim | Proposal plans controlled primary data, supplied tables reference third-party CIC | Primary experiment authorship and acquisition ledger need correction/evidence. Processing public CIC locally is not primary collection. |
| Approval and thresholds | Proposal supervision declaration is visible; TAF assessment fields blank | No documented approval of current labels, late metrics, F1>0.90 or <100ms target is established. |

The final Category C verdict concerns the exact proposed confirmatory experiment supported by this reconstruction. It does not claim every possible CIC reconstruction is impossible. Further source work can improve a secondary benchmark, but it does not supply missing primary matched-shape experiments or prove independent runs automatically.
